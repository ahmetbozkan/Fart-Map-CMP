# Skill: Design Handoff UI

## Purpose
Translate design artifacts into implementable UI tasks with no ambiguity.

## Sources
- `planning/design/SYSTEM.md`
- `planning/design/ImplementationHandoff.md`
- `planning/design/DesignSpecification.md`

## Procedure
1. Read flow mapping from `UXFlowCatalog.md`.
2. Confirm screen spec and state coverage.
3. Extract component and interaction requirements.
4. Bind safety/privacy UX requirements explicitly.
5. Produce story/task acceptance criteria from handoff package.

## Failure recovery
- Missing state definitions: keep story in Backlog and request design completion.

## Validation
- [ ] Flow, screen, and feature links complete
- [ ] Loading/empty/error/offline states defined
- [ ] Platform differences documented if present
