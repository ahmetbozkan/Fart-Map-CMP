# Skill: Testing and Validation

## Purpose
Execute DoR/DoD-aligned validation with reproducible evidence.

## Sources
- `planning/execution/DefinitionOfReady.md`
- `planning/execution/DefinitionOfDone.md`
- `planning/execution/ReviewChecklist.md`

## Procedure
1. Validate readiness gates before implementation.
2. Run required unit/integration/platform checks per item type.
3. Collect evidence against acceptance criteria.
4. Run review checklist prior to Done transition.
5. Record failures and corrective actions explicitly.

## Failure recovery
- If test coverage is missing for touched behavior, add characterization/regression tests before closing item.

## Validation
- [ ] Evidence attached per criterion
- [ ] No gate bypassed
- [ ] Done transition supported by proof
