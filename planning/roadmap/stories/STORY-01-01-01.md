## Acceptance Criteria (Given/When/Then)
1. Given a clean clone and the documented JDK, when `./gradlew :androidApp:assembleDevDebug :androidApp:assembleProdDebug :shared:allTests :umbrella:linkDebugFrameworkIosSimulatorArm64 :androidApp:lintDevDebug` runs, then all pass (module names per ADR-0021; the original wording named the template's `composeApp`).
2. Given the documented `xcodebuild` command for the iPhone simulator, when it runs after the Firebase config is injected locally, then the app builds and launches to a placeholder screen.
3. Given the repository history, when `git log -p` is searched for API keys, `google-services.json` or `GoogleService-Info.plist`, then no tracked secret or config file exists in any commit.
4. Given a pull request, when CI runs, then the Android build, shared tests, iOS build, functions tests and rules tests report status within one workflow.
5. Given `TechStack.md` §3.1, when the story is done, then every row carries the proven version and the date.
