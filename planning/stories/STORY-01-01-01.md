# STORY-01-01-01: Project bootstrap and build pipeline

Status: Done   Epic: EPIC-01-01   Features: foundation for MAP-01, CREATE-01   ADRs: ADR-0015, ADR-0018, ADR-0021

## Goal
A buildable, testable, secret-free codebase on Android, iOS and the backend, with CI.

## Scope
- **In:**
  - project from the KMP template with the owner's identifiers;
  - version catalog on the latest stable set (baseline in `planning/architecture/TechStack.md` §3.1);
  - modules `shared` / `firebaseData` / `umbrella` (ADR-0021);
  - flavors `dev` / `prod` and four Xcode configurations;
  - config templates plus `scripts/inject-config.sh` and `scripts/check-no-secrets.sh`;
  - GitHub Actions: secret scan, Android, iOS, backend;
  - `backend/` with default-deny rules, a smoke function and emulator tests.
- **Out:** DI, navigation and theme (STORY-01-01-02); persistence (STORY-01-01-03); real rules (STORY-01-01-04).

## Acceptance
1. A clean clone builds both Android flavors, runs the shared tests, links the iOS framework and passes lint.
2. `xcodebuild` builds and launches both schemes on the simulator.
3. No secret or config file in any commit.
4. CI reports the Android, shared tests, iOS, functions and rules jobs on a PR.
5. TechStack §3.1 carries the proven versions and their dates.
