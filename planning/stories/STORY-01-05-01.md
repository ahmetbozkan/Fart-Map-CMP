# STORY-01-05-01: Fart detail sheet: marker tap opens the moment

Status: Done   Epic: EPIC-01-05   Features: MAP-02 (marker detail), CREATE-09 (own delete, moved into the sheet), PRIV-02 (coarse area only)   ADRs: ADR-0019, ADR-0023

## Goal
Tapping a marker opens a bottom sheet that shows the moment: flavor, intensity, description and an approximate-area line, with no coordinates and no precise time for other people's farts. The owner's own farts get a Delete action in the sheet that keeps today's confirmation. Reactions, report and block are separate stories (-02, -03).

## Scope
- **In:**
  - **Domain:** `MapFart` gains `description: String?` and `intensity: Double` (defaults keep existing constructors compiling). `MapFartDto` reads `description_text` and `intensity_value`; the mapper and `MapFartDtoTest` cover both.
  - **Presentation:** `MapState.selectedMarkerId` now opens a `FartDetailSheet` (Material3 `ModalBottomSheet`) for the fart in State. Own farts show Delete; others' farts show no action in this story.
  - **Actions/events:** a tap no longer opens the delete dialog directly. New `MapAction.DetailDismissed` (sheet closed) and `MapAction.RequestDeleteFromDetail` (Delete in the sheet sets `pendingDeleteId`). `ConfirmDelete` and `DismissDelete` keep their behavior; a confirmed delete also closes the sheet.
  - **Vanish handling:** when the open fart leaves State (deleted elsewhere, filtered out, removed by the server), the sheet closes; no stale content.
  - **Strings** in `composeResources/values/strings.xml`: sheet summary reuses the marker label sentence; "No words. Just vibes." for an empty description; intensity line; "Approximate area" line; the Delete button label and "Close" (reuses existing copy where it exists).
  - **Analytics:** unchanged. `marker_opened` still fires once per tap (its `isOwn` and `source`).
- **Out:**
  - Reactions bar (-02), Report / Block (-03), the sound play control (-04), author name and avatar (needs the public profile read; no story yet, see Decisions).
  - Share (EPIC-01-10), deep link `fartmap://fart/{id}` (EPIC-01-08), profile navigation.
  - Any new Firestore read. The sheet uses the fart the map already holds.
  - Visual polish beyond the design-system tokens.

## Acceptance
1. **Tap opens the sheet.** `MarkerTapped(id)` on a loaded fart sets `selectedMarkerId`, tracks `marker_opened` once, and does not set `pendingDeleteId` for an own fart. A tap on an id not in State is ignored.
2. **Own fart delete from the sheet.** `RequestDeleteFromDetail` on an open own fart sets `pendingDeleteId` to that id (the confirmation dialog opens over the sheet). On an other's fart it does nothing.
3. **Confirm closes everything.** `ConfirmDelete` sends `MapEvent.DeleteFart(id)` once, clears `pendingDeleteId` and `selectedMarkerId`. `DismissDelete` clears only the dialog and keeps the sheet.
4. **Dismiss.** `DetailDismissed` clears `selectedMarkerId`, `selectedFart` and any open delete dialog; `DismissDelete` clears only the dialog (the sheet stays).
5. **Vanish.** When a refresh no longer contains the open fart, `selectedMarkerId` and `pendingDeleteId` clear (no sheet for a missing fart).
6. **No coordinates, no fine time.** The sheet renders a `FartDetailContent` that has no lat/lng, and for other people's farts reads "less than an hour ago" instead of minutes. Covered by `FartDetailContentTest` (no coordinates in the content, hour granularity rule).
7. **Empty description.** A null or blank description shows the placeholder line, not an empty region.
8. **Mapper.** `MapFartDto` maps `description_text` (absent or blank → null) and `intensity_value` (absent → 0.0, clamped to 0..1). Unknown values never crash the map (existing skip rule).
9. **Parity.** Shared code only; both platforms render the same sheet through Compose. iOS compiles in CI.
10. `scripts/verify.sh --full` green on Windows (iOS in CI); CI green on the PR.

## Decisions
- **Epic split (EPIC-01-05 → -01..-04).** Detail sheet first because reactions, report and block all hang off it; sound (-04) is independent and last. Source: ROADMAP EPIC-01-05 scope; `planning/design/screens/FartDetailSheet.md` (Implementation Handoff). Each story stays reviewable on its own.
- **The sheet reads the fart the map already holds; no new Firestore read.** The map listener already receives the full public document; a second `farts/{id}` read would add cost and an error path for no gain. Source: `DataContracts.md` §3.2 (public fields); `FartDetailSheet.md` Error state is therefore not reachable in this story (the map's own error card covers loading failures).
- **Author name and avatar are deferred.** The user row needs `users/{uid}` (public profile) for each marker opened; that join is cheap to add later but out of this story's acceptance. Source: `FartDetailSheet.md` (user row); `MarkerLabel.kt` already says the username joins later. Recorded so the owner can overrule it.
- **Intensity is shown as a percentage line**, not a slider or bar, because the sheet is read-only. Source: `FartDetailSheet.md` (flavor + intensity row); `DataContracts.md` §3.2 (`intensity_value` 0.0..1.0).
- **Other people's age is at hour granularity.** Minutes and "just now" collapse to "less than an hour ago"; days stay as days. Source: `FartDetailSheet.md` ("no precise timestamp below hour granularity for others' farts").
- **"Approximate area" is a label, not a place name.** The fuzzed point is already ~a geohash-6 cell; reverse geocoding would add a service and a privacy question, so no place name ships here. Source: ADR-0019; `FartDetailSheet.md` ("coarse area line").
- **A confirmed delete closes the sheet too.** The sheet's content would otherwise show a removed fart. Source: `FartDetailSheet.md` Exit routes ("delete success returns to Map with the marker removed").
- **The sheet reads `selectedFart`, a snapshot taken from the loaded list.** Panning away keeps the sheet open (it reads `loaded`, not the viewport slice); a refresh that drops the fart closes it. Source: `FartDetailSheet.md` (sheet dismiss only by the user); plan review finding.
- **The own-fart variant shows visibility** (`log_visibility_*` labels), the spec's badge. Cheap, no new read. Source: `FartDetailSheet.md` (Success state).
- **Dismissing the sheet drops a delete dialog over it** and dismissing the dialog keeps the sheet (one shared dismiss path). Source: plan review finding (orphaned dialog).
- **Report and Block are not in the sheet yet.** They ship in -03 (they need the report sheet and blocks). The own-fart variant is complete here. Source: `FartDetailSheet.md` (Safety and Privacy UX), ROADMAP split.
