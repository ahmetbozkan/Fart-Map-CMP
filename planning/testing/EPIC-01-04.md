# EPIC-01-04 manual test plan: Log Fart

> Owner's end-of-epic check. Covers STORY-01-04-01 to -06; nothing is deferred. Tick each case per platform; for a failure, open an issue (template at the end) and keep going. The format is in `planning/testing/README.md`.

**What this epic built:**
- the create path: public doc with the fuzzed point plus the owner-only `private/location`, and the server re-check (-01);
- the Log Fart screen from the map button: location step, visibility with the age-based default, "Let It Rip", pending and offline states (-02);
- the detailed fields: time, avatar, sound, flavor, intensity, caption, the locked voice row (-03);
- drafts that survive a kill, with Keep / Discard on back (-04);
- delete your own fart from the map, with the server purge of the precise location (-05);
- the one-time "link Google" offer after a guest's first online log (-06).

Not built yet: the marker detail sheet, reactions, sound playback, unlock sheets (later epics).

## Before you start

- [ ] **Dev catalog seeded** (`OwnerTodo.md` A) so the avatar and sound rows have items.
- [ ] **Latest `main` pulled;** CI deployed `onFartCreated` and `onFartRemoved` to `fart-map-dev` (Firebase console → Functions lists both).
- [ ] **Dev configs in place:** `bash scripts/inject-config.sh` on each machine you build on.
- [ ] **Android:** `MAPS_API_KEY_DEV` in `androidApp/secrets.properties`; install with `gradlew.bat :androidApp:installDevDebug`, variant `devDebug`. Emulator location set via Extended controls → Location.
- [ ] **iOS (on the Mac):** scheme **FartMap Dev**, an iPhone simulator; set Features → Location → Custom Location.
- [ ] **Accounts:** one adult guest, one teen guest (age gate birth year 13–17), one Google account that is **not** yet used in Fart Map, and one Google account that already has its own Fart Map.
- [ ] **Console open:** Firestore → `farts` (and `farts/{id}/private/location`), dev project.
- [ ] **Logs:** Logcat filtered on `System.out` / Xcode console. Logs must never contain coordinates, a uid or a token.

**Fresh install:** Android: uninstall, or Clear storage. iOS: delete the app. A new guest always gets a fresh nudge state.

## Cases

### 1. Quick log
Android x iOS ☐
1. Fresh adult guest, grant location on "Use my location" / center on me, tap the log button on the map, then "Let It Rip".

**Expected:** the screen closes, a success snackbar shows, the map moves to the new marker (faded while unsynced, then solid). Console: `farts/{id}` exists with a fuzzed point; `private/location` exists with the precise point in the same geohash-6 cell.

### 2. Location step
Android x iOS ☐
1. Fresh install, never asked for location: open Log Fart.
2. Tap "Use my location", deny. Place the pin, log.

**Expected:** opening never prompts. Deny → the pin picker works and the log succeeds. Android shows the approximate hint "Roughly here. Move the pin if this isn't right."

### 3. Visibility default
Android x iOS ☐
1. Adult: first log preselects PUBLIC. Pick FOLLOWERS, log, open Log Fart again.
2. Teen guest: open Log Fart.

**Expected:** adult first open = PUBLIC; the next open = last choice. Teen never sees PUBLIC and defaults to FOLLOWERS.

### 4. Offline log
Android x iOS ☐
1. Airplane mode, log.
2. Go back online.

**Expected:** "Saved locally" snackbar, faded marker; after reconnecting the marker turns solid and the docs appear in the console.

### 5. FOLLOWERS log on the Everyone filter
Android ☐ iOS ☐
1. Filter Everyone, log with FOLLOWERS.

**Expected:** the map switches to Mine and shows it.

### 6. Detailed fields
Android ☐ iOS ☐
1. Untouched quick log: defaults are Bean Bandit, Stinky, middle intensity, no sound.
2. Change every field and log. Check the console doc: `timestamp_epoch_ms`, `avatar_id`, `flavor_level`, `intensity_value`, `description_text`, `sound_id`.
3. Type a caption past 280 with emoji; use the Gboard / iOS keyboard.
4. Airplane mode on a fresh install: open Log Fart.
5. Tap the voice row.

**Expected:** values match. The caption stops at 280 without broken emoji and the cursor doesn't jump. Offline, avatar and sound rows still show starter items. The voice row opens a "coming later" sheet with no buy or ad button.

### 7. Drafts
Android x iOS ☐
1. Fill a few fields, kill the app, reopen Log Fart.
2. Pick a time, kill, reopen. Leave the time untouched, kill, reopen.
3. Back on a filled form: Keep, reopen; Discard, reopen. Tap outside the dialog. Rotate with the dialog open (Android).
4. Force a failed submit (rules rejection), kill, reopen.
5. Log successfully, reopen.

**Expected:** fields and a note come back, location is looked up again; a picked time returns, an untouched time shows the new open time. Keep restores, Discard is fresh, outside tap stays on the form, the dialog survives rotation. A failed submit keeps the fields. A successful log gives a fresh form.

### 8. Delete own fart
Android x iOS ☐
1. Tap an own marker: the dialog "Take this one back?" shows. Keep it, then try again and Delete.
2. Tap another user's marker (Everyone filter).
3. Airplane mode: delete an own marker, then reconnect. Rotate with the dialog open (Android).

**Expected:** Keep it leaves the marker; Delete removes it at once, also offline. Console: `is_removed = true`, `removed_reason = USER_DELETED`, and `private/location` is gone a few seconds later. Another user's marker opens nothing. The dialog stays on rotation.

### 9. Account-link nudge: shows once
Android x iOS ☐
1. Fresh install, start as an adult guest. Log a fart **online**.
2. Tap "Not now". Log again.

**Expected:** after the first log the success snackbar shows and the dialog "Keep this one forever?" appears with "Link Google" / "Not now". "Not now" closes it. The second log shows no dialog. Tapping outside the dialog also closes it.

### 10. Nudge waits for an online log
Android x iOS ☐
1. Fresh install, guest, airplane mode, log.
2. Go online, log again.

**Expected:** the offline log shows no dialog. The next online log shows it.

### 11. Nudge: link success
Android ☐ iOS ☐
1. Fresh guest, log online, tap "Link Google", pick the unused Google account.

**Expected:** the Google sheet opens; afterwards the snackbar "Linked. Your legacy is safe now." shows; Profile no longer shows the link card; the fart is still on the map under Mine.

### 12. Nudge: cancel and conflict
Android x iOS ☐
1. Fresh guest, log online, tap "Link Google", close the Google sheet.
2. Fresh guest again, log online, link with the Google account that already has its own Fart Map.

**Expected:** cancel: no message, the dialog is gone, it doesn't come back on the next log; the Profile card still offers linking. Conflict: the snackbar "That Google account already has its own Fart Map. You're still here as a guest." shows, you stay a guest.

### 13. Nudge is per user
Android x iOS ☐
1. Link-free guest who saw the nudge: when the sign-out button exists (EPIC-01-07) sign out and start a new guest, log online.

**Expected (manual only; sign-out UI is a later epic):** a brand-new guest sees the nudge again. A linked user never sees it.

### 14. Accessibility
Android x iOS ☐
1. With TalkBack / VoiceOver: walk the Log Fart screen, the delete dialog and the nudge dialog.

**Expected:** flavor steps, slider, avatar and sound chips, the voice row, the date button, the picker buttons, and both dialog buttons are labelled. A pending marker is announced as posting.

## Not in this epic

- Sound playback and preview; the voice row and locked items only open an info sheet or stay inert (EPIC-01-05 / -06).
- The sign-out button and the Rank link card (EPIC-01-07).
- The notification prompt and starter-pack offer that also follow a first log (later stories).
- App Check (deferred) and the ADR-0026 fine-location decision (still Proposed).
